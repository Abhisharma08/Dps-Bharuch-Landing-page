# **App Name**: DPS Anand Admissions

## Core Features:

- Inquiry Form: A form to collect parent details and student's intended grade, triggering a callback from the admissions counselor.
- Dynamic FAQ: AI powered chatbot providing dynamic answers to the question on admissions
- Campus Tour Booking: Allow parents to book a campus tour through a calendar integration.
- Digital Brochure: Enable a digital brochure that the LLM tool will help generate after an initial query form is filled. Include key details, student testimonials, and faculty information in a brochure format.

## Style Guidelines:

- Primary color: Professional blue (#002D62) for trustworthiness. Chosen for its ability to convey stability and reliability.
- Background color: White (#FFFFFF) and light grey (#F9FAFB) for clean sections. This scheme prioritizes readability and provides a neutral canvas.
- Accent color: Vibrant orange (#FF7F50) for CTAs, indicating a warm, inviting action. Its use should create a sense of optimism.
- Body and headline font: 'Poppins' (sans-serif) for a modern and clean look.
- Responsive design to ensure the page looks great on mobile, tablet, and desktop devices.
- Use clear and professional icons for the bullet points in the Hero Section and feature cards in the 'Why Choose Us?' Section.
- Subtle transitions and animations to improve user experience and provide a modern feel.
